One-time setup on this phone
  1. Open GitHub → new fine-grained token (signed in as Callahan2026).
  2. Name it Board control, expiration 1 year.
  3. Repository access: Only select repositories → dana-loads.
  4. Permissions → Repository → Contents: Read and write.
  5. Generate, copy it, paste below, tap Save.

The key stays only in this phone's browser. Nobody else can change the board without it.
